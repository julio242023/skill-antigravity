## 🌟 ¿Qué es una Skill en Antigravity?

Una **Skill** en Google Antigravity es un paquete modular de instrucciones y heurísticas empaquetado en una carpeta con un archivo `SKILL.md`. Contiene metadatos en formato YAML frontmatter con campos como `name` y `description`.

Cuando el usuario solicita una tarea o interactúa con el IDE, Antigravity detecta la intención y activa la skill pertinente de forma autónoma o explícita, guiando al modelo a seguir flujos rigurosos, seguros y optimizados.

---

## 📂 Estructura de una Skill

```text
skills/<nombre-de-la-skill>/
├── SKILL.md                 # Archivo obligatorio con YAML frontmatter y directivas
├── references/              # (Opcional) Documentación extendida y referencias técnicas
├── examples/                # (Opcional) Implementaciones de referencia
├── scripts/                 # (Opcional) Scripts de automatización y verificación
└── templates/               # (Opcional) Plantillas base de código
```

### Formato estándar de `SKILL.md`:
```markdown
---
name: nombre-de-la-skill
description: Descripción precisa de las capacidades y detonadores de la skill.
---

# Título de la Skill

## When to Use
- Criterios específicos para su activación.

## Core Concepts & Guidelines
- Patrones recomendados, pasos de implementación y restricciones.
```

## ⚡ Cómo Instalar y Usar

### 1. Instalación Global (Recomendado para tenerlas siempre disponibles)
Para que todas tus instancias de Antigravity reconozcan las skills globalmente:

**En Windows (PowerShell):**
```powershell
# Clonar el repositorio
git clone https://github.com/julio242023/skill-antigravity.git "$HOME\skill-antigravity"

# Copiar a la carpeta global de habilidades de Antigravity
New-Item -ItemType Directory -Force -Path "$HOME\.gemini\skills"
Copy-Item -Path "$HOME\skill-antigravity\skills\*" -Destination "$HOME\.gemini\skills\" -Recurse -Force
```

**En Linux / macOS:**
```bash
git clone https://github.com/julio242023/skill-antigravity.git ~/skill-antigravity
mkdir -p ~/.gemini/skills
cp -r ~/skill-antigravity/skills/* ~/.gemini/skills/
```

### 2. Instalación por Proyecto / Workspace
Si prefieres habilitar skills sólo dentro de un proyecto específico:

```bash
# En la raíz de tu proyecto
mkdir -p .agents/skills
# Copia las skills que necesitas
cp -r /ruta/a/skill-antigravity/skills/<skill-name> .agents/skills/
```

## ✍️ Cómo Crear tu Propia Skill

1. Crea una carpeta dentro de `skills/<mi-skill>/`.
2. Agrega el archivo `SKILL.md` con su frontmatter YAML obligatorio:
   ```yaml
   ---
   name: mi-skill
   description: Explica qué resuelve esta habilidad y los términos clave que deben activarla.
   ---
   ```
3. Detalla las secciones de contexto, criterios de activación, ejemplos de uso y directrices de código.
4. (Opcional) Añade carpetas auxiliares: `references/`, `examples/`, `scripts/`.
5. Envía tu contribución mediante un Pull Request.
